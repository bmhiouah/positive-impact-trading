# Pre-MVP vision documents

These files are the **original idea** for the project: an AI-powered quant
research platform (market-data engineering, RAG, LangGraph agents, MCP servers,
LLM evaluation, observability, backtesting). They predate the current direction
and are kept for context only.

The shipped MVP is a much smaller thing — a long-only algorithmic **paper-trading
lab** with one fixed IB Gateway session, a cash/equity camembert and systematic
TP/SL brackets. See [`../ARCHITECTURE.md`](../ARCHITECTURE.md) for what is
actually built.

| File | What it was |
|---|---|
| `ROADMAP.md` | original phased roadmap for the AI research platform |
| `base_idea.txt` | ASCII data-flow sketch of the multi-agent architecture |
| `description.txt` | one-paragraph original project description |
| `original_tree_idea.txt` | first proposed directory layout |
| `architecture-ia-marketmind.png` | the original AI architecture diagram |

None of these files are imported, executed or required at runtime.
